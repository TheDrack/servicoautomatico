# 🤖 Engenharia de Automação & Data Pipeline

Repositório focado em soluções de automação de alto nível, transitando desde RPA tradicional até sistemas de monitoramento em tempo real com IA.

## 🚀 Projetos em Destaque

### 1. Real-Time WhatsApp Bridge (High-Level)
O motor principal deste repositório. Uma arquitetura híbrida que utiliza:
- **Selenium:** Para autenticação e bypass de segurança.
- **Requests:** Para orquestração de metadados.
- **WebSockets:** Para captura de mensagens em tempo real com `asyncio`.
- **LGPD Compliant:** Implementação de pseudonimização e proteção de dados sensíveis.

### 2. SnakeIA - Aprendizado por Reforço
Estudo de Inteligência Artificial aplicada, utilizando **TensorFlow** e **DQN** (Deep Q-Network) para treinar um agente autônomo.

### 3. Gerenciador de Robôs Pro
Interface gráfica em **Tkinter** com orquestração de threads para gerenciar múltiplos processos Python simultaneamente.

## 🛠️ Stack Tecnológica
- **Linguagem:** Python 3.9+
- **Bibliotecas:** TensorFlow, Selenium, Asyncio, Websockets, MySQL Connector.
- **DevOps:** Docker, Environment Variables (.env), Logging Estruturado.
